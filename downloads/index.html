Install and verify

Linux, macOS, BSD or Android CLI: unpack tar -xzf FILE.tar.gz, then execute ./noqeri-vVERSION-OS-CPU/bin/noqeri --version. On Android, the NDK executable requires a compatible terminal environment and Android API level.

Windows: use PowerShell Expand-Archive FILE.zip, then execute bin/noqeri.exe --version.

Integrity: compare sha256sum FILE with the published release SHA-256. Windows: Get-FileHash FILE -Algorithm SHA256.

GPU-specific packages are only displayed after validation against their GPU architecture and driver. A general WGSL shader compiler does not imply CUDA, ROCm, Vulkan, Metal or Direct3D compatibility.
